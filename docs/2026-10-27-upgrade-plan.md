# MuseRadar AI 第二阶段实施计划（已确认）

日期：2026-10-27。用户确认后执行；真实模型先完成接口，稍后配置，不购买服务。

## 范围与实现
1. 新增独立四步工作台，沿用真实研究快照和知识库，保留原应用源码，使用 IndexedDB 保存评论、任务、复核与方案。主入口切换到新工作台，六个页面哈希仍兼容。
2. 三个已实测评论社区：Hacker News、Travel Stack Exchange、History Stack Exchange。后两者先检索关键词匹配的问题，再读取其问题下的评论；不冒充问题/回答或全平台评论。Discourse 无已验证合适站点，暂不列为已支持。
3. 连续分页、HN 时间分片、逐页去重与断点、停止/继续、重试、请求配额与 backoff、明确完整/部分状态。数据源范围固定到任务创建时；更新创建新任务；公开接口并不保证全平台覆盖。
4. 五档意愿与情绪、已参观/无关/待核实分离；模型结果引文必须存在于原文；人工修改保留记录；资源/文本变更使模型缓存失效。
5. 近期有效评论逐条进入分析。画像按需求分群，不推断人口身份；AI 模式下所有有效记录需完成或人工排除后才生成方案；完整成员 ID 与分档分布保留，AI 方案分批摘要再汇总，证据 ID 校验。
6. 新增无依赖 Node 后端，默认只监听本机，服务端环境变量配置 OpenAI-compatible chat completions 接口，不硬编码供应商。状态接口不泄露密钥；API 需操作者令牌；CORS 精确来源；限制请求大小；任务逐批执行与服务器磁盘保存。前端 GitHub Pages 独立，模型/后端缺失时显示未连接。
7. 覆盖真实来源、分页完整性、AI 输出验证、防注入与来源核验、五档筛选、历史意愿边界、汇总全覆盖、后端请求安全、浏览器操作；更新指南并部署 Pages。

## 完成门槛
当前无模型凭据。验收能完成真实数据获取、人工/规则分档、筛选、画像和可配置 AI 完整调用链。不能声称已完成真实模型线上推理。后端提供本机可运行入口与独立部署说明；不擅自购买或绑定卡。
