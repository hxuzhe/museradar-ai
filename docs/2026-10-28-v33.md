# MuseRadar 3.3 任务删除与在线数据

按用户要求移除默认历史评论，空数据启动。旧工作空间自动清理 visitor-review、Figshare 来源和已知历史 ID；关联分析、审核、错误和方案清理。历史原始数据迁移至 research/legacy-fixtures 仅用于回归；原静态 URL 保留空兼容文件以防浏览器旧缓存导入失败。

任务新增 postIds 和 membership；按 ID 和正文去重后记录 canonical ID，每个任务都保存自身获取过的评论集合。删除只移除本任务独占、且非独立导入的评论；同步清理相关分析及方案，视图自动聚合。一次性内存撤销不写入持久化备份。

旧任务缺少逐条关联，按 sourceId、发布时间范围、采集时间与 HN 关键词恢复，标记 legacy-estimated 并在确认框说明不确定性。未关联的数据保留为独立记录，避免猜测性误删。

修复“查看任务评论”此前只按平台筛选的问题。运行中禁止删除，删除前显示实际涉及数量。全部单元验证使用隔离数据，不调用真实模型。
