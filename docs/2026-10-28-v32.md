# MuseRadar AI 3.2 使用与实现说明

## 评论判别和宣传方案分开设置
评论判别仍使用 server/model-core.mjs 的 policy + analysisInstruction，区分情绪、历史反馈和未来意愿，不从缺失信息推断身份。评论判别、分批证据整理和压缩关闭思考；只有最终的群体宣传方案开启 DeepSeek 思考模式。最终方案输出上限 12000 tokens，评论与整理保留 6000；上限包含供应商计入的思考输出，并非固定消耗。调用模式由后台路由确定，前端不能自行提高。

## 全部评论词云
在“选择数据与获取”查看词云。全量统计当前浏览器已载入的非手动测试评论，包含研究快照、在线获取和导入，不受分页、筛选限制；获取或导入后自动更新。使用浏览器中英文分词、文化词典和停用词表，按真实词频绘制 SVG；查看涉及评论数，点击词语检索证据，导出 CSV 或 SVG。未做语义聚类，不代表意愿强弱；历史来源与近期来源混合时明确提示。无有效词语时展示空状态，不编造词语。

## 普通访客与授权模式
打开原 GitHub 地址即可成为普通访客。点击“网站 AI · 查看用量”，在访问模式面板输入所有者提供的密码进入授权模式。密码经 HTTPS 提交后台，后台使用随机盐 + PBKDF2-SHA256 验证，密码不保存到浏览器、工作空间或 GitHub。只有加盐记录存放于后台秘密配置；不在文档记载密码。

授权解除当前会话的评论、方案、摘要、操作次数和同网络每日体验限额；不解除同网络每分钟 6 次、全站并发 2 个、全站每日 100 次模型调用 / 500000 tokens 的共享保护，亦不取消供应商限流和余额要求。授权不是管理员权限，不能调整服务配置。密码尝试每个网络每 10 分钟最多 8 次。退出授权、会话过期、新建会话或密码变更后需重新验证。更换网络后会话失效。

点击“退出授权模式”恢复普通额度；已使用数量不会清零。查看状态、输入密码、词云均不调用模型。失败模型请求可能计入保守预算。

## 验证边界
隔离测试验证词频口径、字符转义、授权提升/退出/密码轮换、恶意自授权失败、密码尝试限制、全站预算不被授权绕过，以及实际 Worker 发出请求的 thinking 参数。真实 DeepSeek 调用未执行，未验证余额及真实生成质量。

## 在线验收（2026-10-28）

GitHub Pages 与后台均已发布；实际浏览器验证普通访客 → 授权模式 → 退出授权，未调用模型。词云基于现有 306 条评论（其中 256 条历史反馈）显示；CSV 和 SVG 实际下载成功，点击“铁路”跳转到包含该词的 89 条原文筛选结果。样本数由当前浏览器数据集决定，不是网站固定指标。
